# Discord Auto Interaction Sender & Clicker - Node.js CLI版

Node.js環境で動作する、Discordの**スラッシュコマンド等(Application Command)を一斉送信し、表示されたボタンを指定回数並列で自動クリックするツール**です。
設定をフォルダごとに分けて管理し、必要なデータが不足している場合はCLIから自動的に情報入力を求めます。

## 必要要件
* **[Node.js v21 以上](https://nodejs.org/) 推奨**
  * モジュールを別途インストールせずに、単体のファイルだけで動作させることが可能です（標準で `WebSocket` と `fetch` に対応）。
  * **※ Node.js v18 〜 20 で使用する場合**は標準WebSocketが含まれていないため、`npm install ws` を実行して `ws` モジュールを導入してからご使用ください。

## 📂 ディレクトリ構成
`target.js` (本ツール) と同じ階層に、任意の名前のフォルダ(例: `conf1`)を作成し、設定ファイルを配置してください。

```text
.
├── target.js           <-- ツール本体
└── conf1/              <-- 設定フォルダ (名前は自由)
     ├── token.txt      <-- トークンリスト
     ├── channels.txt   <-- チャンネルIDリスト (未設定・空でも動作可)
     ├── settings.json  <-- 動作設定ファイル
     └── clickData.json <-- 自動生成 (送信済みのボタンとメッセージ情報を保持し、次回再利用)
```

## ファイルの書き方

各ファイルはUTF-8で保存してください。

### 1. `token.txt` (必須)
Discordのアカウントトークンを1行に1つずつ入力してください。
```text
MTQzMTI0NTAzMTU4MjMzOT...
MTExMTMzMDUxNDE2OTcMTk...
```

### 2. `channels.txt` (任意)
コマンドを送信する先のテキストチャンネルIDを1行に1つずつ入力してください。
※ このファイルが**空の場合、設定したサーバー(GUILD_ID)内のテキストチャンネルをツールが自動取得して実行するか**を聞かれます。

```text
163963826...
937553631...
```

### 3. `settings.json` (任意 / CLIからの入力も可)
動作の詳細設定を行います。設定が不足している場合、CLI画面で自動的に質問が表示されるため、事前に作成しなくても利用可能です。

```json
{
  "GUILD_ID": "123456789012345678",
  "COMMAND_NAME": "bump",
  "CLICK_COUNT": 3,
  "COMMAND_ARGS": {
    "amount": 100,
    "user": "1234567890"
  }
}
```

| キー | 説明 |
| --- | --- |
| `GUILD_ID` | コマンドを送信するサーバー(Guild)のID。 |
| `COMMAND_NAME` | 実行・検索するコマンド名（例： `bump` 等）。 |
| `CLICK_COUNT` | 表示されたボタンを一斉クリックする回数。（`0`の場合はコマンド送信のみ） |
| `COMMAND_ARGS` | (任意) コマンドに渡す引数をキー・バリュー形式で指定します。ここで指定しなかった必須引数は、実行時にプロンプトで要求されます。 |

## 起動と使い方の流れ

1. コマンドプロンプト (またはターミナル) を開き、`target.js` があるディレクトリに移動します。
2. 以下のコマンドを実行します。
   ```bash
   node target.js
   ```
3. `folder name >` と表示されたら、作成した設定フォルダ名（例: `conf1`）を入力します。
4. 設定ファイルの読み込み後、**データに不足（`GUILD_ID`、`COMMAND_NAME` 等）がある場合は入力プロンプトが出ます**ので入力してください。
5. 前回の `clickData.json` (メッセージとボタンIDの再利用データ)が存在する場合は、コマンドの再送信をスキップし、そのままボタンを一斉クリックするかを尋ねられます。
6. 設定完了後、`Ready? >` と表示されたら、`y` を入力して開始します。

## ログの見方

コンソールには以下のカラーログが表示されます。

* <span style="color:cyan">**[INFO]**</span> : ツールの状態、進行フェーズ（WebSocket接続中、検索結果など）
* <span style="color:green">**[SUCCESS]**</span> : 送信・ボタン検知・クリック成功
* <span style="color:yellow">**[WARN]**</span> : レート制限の検知、タイムアウト待機、警告
* <span style="color:red">**[ERROR]**</span> : エラー発生 (トークン無効、APIエラー、ネットワークエラーなど)
